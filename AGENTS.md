# Codex bridge

Questo e' un repository Git autonomo dentro Mechloops AIOS.

1. Prima di agire, esegui `git status --short --branch` in questa root.
2. Se esiste, leggi integralmente `./CLAUDE.md`: e' la fonte canonica del
   contesto e delle regole specifiche del progetto.
3. Quando il parent AIOS e' disponibile, leggi anche
   `../../AGENTS.md` e `../../context/codex-claude-parity.md`.
4. I nomi di tool, skill e slash command specifici di Claude Code vanno
   tradotti tramite la guida di parita'; non duplicare i workflow locali.
5. Le regole specifiche di `CLAUDE.md` prevalgono per questo repository;
   le regole di sicurezza e gestione Git del parent restano valide.
